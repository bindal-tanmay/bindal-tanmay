## 🔌 PERIPHERAL BENCH

```text
GPIO    PIN → MODE → PULL → SPEED → OUTPUT
UART    TX → RX → BAUD → FRAME → SERIAL DATA
SPI     SCK → MOSI → MISO → CS
I²C     SCL → SDA → ADDRESS → ACK/NACK
TIMERS  CLOCK → PRESCALER → COUNTER → EVENT
```

## 🚀 EXPERIMENTS / PROJECTS

### ⚡ Parameterized INT8 TPU Core with Systolic Array

`SystemVerilog` · `Xilinx Vivado` · `AMD/Xilinx Artix-7 FPGA` · `Logic Synthesis`

```text
 Matrix Input (8x8 INT8)
 ├── Controller FSM ──────── State orchestration & sync
 ├── Input-Skew Buffer ───── Operand propagation alignment
 ├── Weight Buffer ───────── Weight stationing
 └── Systolic Array ──────── 64 Processing Elements (MAC + 32-bit Accumulator)
```

**Focus:** Designed an 8x8 INT8 hardware TPU core with 64 parallel processing elements doing 32-bit accumulation for GEMM workloads. Built a self-checking testbench in SystemVerilog achieving 64/64 verified outputs, resolved datapath clock-edge alignment, and established the synthesis flow for Artix-7 FPGA implementation.

## 🧪 ENGINEERING PHILOSOPHY

Don't just ask:

> "How do I make this work?"

Ask:

> "What is actually happening?"

```text
Why isn't the LED blinking or matrix multiplication outputting correctly?
        ↓
Clock / Reset Sync?
        ↓
Input Skew Buffer?
        ↓
FSM State?
        ↓
Datapath & MAC Units?
        ↓
Register / Alternate Function?
        ↓
Physical Connection / FPGA Pins?
        ↓
Logic Waveform Analysis?
        ↓
FOUND IT. ⚡
```
